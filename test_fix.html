Тест исправления проблемы с формами редактирования

Проблема: при открытии диалога редактирования операции, он запоминает состояние и при следующем открытии открывается такое же. Это неверно т.к. для расхода и для аванса разные наборы свойств - у аванса и перевода нет свойства "Распределение".

Исправления, которые мы внесли:

  1. Добавлена функция setupDialogCloseHandlers() которая сбрасывает формы при закрытии диалогов
  2. В функции openEditEntryDialog() добавлен сброс формы перед заполнением: form.reset()
  3. Обработчики закрытия диалогов добавляются для всех диалогов редактирования

Проверка:

  • При закрытии диалога editExpenseDialog форма должна сбрасываться
  • При закрытии диалога editTransferDialog форма должна сбрасываться
  • При закрытии диалога editLoanDialog форма должна сбрасываться
  • При закрытии диалога viewEntryDialog форма должна сбрасываться
  • При открытии диалога редактирования для нового типа операции форма должна быть чистой
